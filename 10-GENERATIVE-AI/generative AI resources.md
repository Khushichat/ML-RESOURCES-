# Generative AI and LLM Resources

## Layer 1: transformer foundations

- [nlp-with-transformers/notebooks](https://github.com/nlp-with-transformers/notebooks) - use the transformer, embeddings, BERT, datasets, and fine-tuning material from the NLP track.
- [Hugging Face LLM Course](https://huggingface.co/learn/llm-course) - current model, dataset, fine-tuning, and deployment guidance.
- [The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/) - accessible conceptual explanation.

## Layer 2: build systems

Study in this order: `LLM/` -> `Prompt-Engineering/` -> `Embeddings/` -> `Vector-Database/` -> `RAG/` -> `Fine-Tuning/` -> `LoRA/` -> `QLoRA/` -> `Agents/` -> `Evaluation/`.
