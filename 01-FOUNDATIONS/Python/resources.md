# Python Resources

## Primary repositories

- [fractal-analytics-academy/python-for-data-science](https://github.com/fractal-analytics-academy/python-for-data-science) - notebooks, guided exercises, solved use cases, and practice problems.
- [Stephen-Rimac/Python-for-Data-Scientists](https://github.com/Stephen-Rimac/Python-for-Data-Scientists) - Python basics, data structures, functions, NumPy, Pandas, and project files.
- [gtolomei/python-for-datascience](https://github.com/gtolomei/python-for-datascience) - university-style lecture notebooks, PDFs, and exercises.

## Recommended order

1. `basics/`: syntax, control flow, functions, files, exceptions, modules.
2. `numpy/`: arrays, broadcasting, indexing, vectorization, linear algebra.
3. `pandas/`: loading data, cleaning, joins, groupby, reshaping, time series.
4. `exercises/`: reproduce a notebook, solve a variation, then write tests.
