# Mathematics for Machine Learning

## Primary repositories

- [dair-ai/Mathematics-for-ML](https://github.com/dair-ai/Mathematics-for-ML) - linear algebra, calculus, optimization, probability, statistics, and ML mathematics.
- [felipe-tobar/Maths-for-ML](https://github.com/felipe-tobar/Maths-for-ML) - academic lecture notes and tutorials covering linear algebra, geometry, calculus, optimization, probability, and statistics.
- [Mathematics for Machine Learning](https://mml-book.github.io/) - reference textbook with a free author-provided version.

## Recommended order

1. `Linear-Algebra/`: vectors, matrices, projections, eigenvalues, SVD.
2. `Calculus/`: derivatives, gradients, chain rule, and partial derivatives.
3. `Probability/`: distributions, conditional probability, Bayes, expectation.
4. `Statistics/`: sampling, estimation, testing, regression, uncertainty.
5. `Optimization/`: loss functions, convexity, gradient descent, regularization.

Use small NumPy implementations to connect each topic to a model.
