# Machine Learning Study Resources

A curated list of free, legitimate machine learning books and study material available online. Organized by level and topic. All links go to official author/publisher pages — please respect each resource's license terms.

## How to use this repo
This repo links out to free resources rather than hosting copyrighted PDFs directly (most "free to read" books aren't free to redistribute). A few resources below are open-licensed and safe to fork/mirror — marked with 🟢.

---

## 📐 Math Foundations

- **[Mathematics for Machine Learning](https://mml-book.github.io/)** — Deisenroth, Faisal, Ong (Cambridge Univ. Press)
  Free PDF. Covers linear algebra, calculus, probability — the prerequisites for everything below.

---

## 📘 Core ML Textbooks

- **[An Introduction to Statistical Learning](https://www.statlearning.com/)** — James, Witten, Hastie, Tibshirani
  Free PDF, R and Python editions. The standard beginner-to-intermediate stats/ML text.

- **[The Elements of Statistical Learning](https://hastie.su.domains/ElemStatLearn/)** — Hastie, Tibshirani, Friedman
  Free PDF. The more advanced/mathematical companion to ISL.

- **[Pattern Recognition and Machine Learning](https://www.microsoft.com/en-us/research/publication/pattern-recognition-machine-learning/)** — Christopher Bishop
  Free PDF via Microsoft Research. Classic Bayesian-flavored ML text.

- **[The Hundred-Page Machine Learning Book](https://themlbook.com/wiki/doku.php)** — Andriy Burkov
  Free sample chapters + wiki summary; full book is paid.

---

## 🧠 Deep Learning

- **[Deep Learning](https://www.deeplearningbook.org/)** — Goodfellow, Bengio, Courville (MIT Press)
  Free HTML/PDF chapters. The definitive DL textbook.

- 🟢 **[Dive into Deep Learning](https://d2l.ai/)** — Zhang, Lipton, Li, Smola
  Free, interactive, Apache 2.0 licensed. GitHub repo: [d2l-ai/d2l-en](https://github.com/d2l-ai/d2l-en) — you can legitimately fork this one.

- 🟢 **[Neural Networks and Deep Learning](http://neuralnetworksanddeeplearning.com/)** — Michael Nielsen
  Free online book, CC BY-NC licensed.

- **[A Brief Introduction to Neural Networks](https://www.dkriesel.com/en/science/neural_networks)** — David Kriesel
  Free PDF, author-hosted.

---

## 🎮 Reinforcement Learning

- 🟢 **[Reinforcement Learning: An Introduction](http://incompleteideas.net/book/the-book.html)** — Sutton & Barto
  Free PDF, author explicitly permits sharing for teaching/learning purposes.

## 🎲 Bayesian & Probabilistic Methods

- 🟢 **[Probabilistic Programming & Bayesian Methods for Hackers](https://github.com/CamDavidsonPilon/Probabilistic-Programming-and-Bayesian-Methods-for-Hackers)** — Cam Davidson-Pilon
  Free, MIT licensed, full GitHub repo with Jupyter notebooks — fork directly.

- 🟢 **[Think Bayes](https://greenteapress.com/wp/think-bayes/)** — Allen Downey
  Free PDF, CC BY-NC licensed.

## ⚠️ A note on copyright

Books marked 🟢 are open-licensed and safe to fork or mirror in your own repo. The rest are free to read/download for personal study from their official page, but redistributing the PDF elsewhere (including re-uploading to your own repo) isn't authorized by their license — please link to them instead, as this README does.
