# Deep Learning Resources

- [PyTorch Tutorials](https://pytorch.org/tutorials/) - tensors, datasets, models, autograd, optimization, saving/loading, and complete workflows.
- [mrdbourke/pytorch-deep-learning](https://github.com/mrdbourke/pytorch-deep-learning) - practical course material and online book.
- [yunjey/pytorch-tutorial](https://github.com/yunjey/pytorch-tutorial) - basics through linear/logistic regression, ANN, CNN, RNN, GAN, VAE, and image captioning; MIT licensed.
- [karpathy/nn-zero-to-hero](https://github.com/karpathy/nn-zero-to-hero) - neural networks from first principles.
- [Dive into Deep Learning](https://d2l.ai/) - interactive, implementation-focused textbook.

## Recommended order

Tensors -> datasets and dataloaders -> modules -> training loops -> MLPs -> CNNs -> sequence models -> transfer learning -> deployment and monitoring.
