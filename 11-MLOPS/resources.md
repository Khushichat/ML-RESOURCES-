# MLOps Resources

- [chen115y/MLOpsLearning](https://github.com/chen115y/MLOpsLearning) - Python, SQL, statistics, data work, classical ML, DL, NLP, GenAI, RAG, explainability, and MLOps.
- [dpleus/mlops](https://github.com/dpleus/mlops) - practical platform combining Docker, Prefect, MLflow, FastAPI, Prometheus/Grafana, and Streamlit.
- [Made With ML](https://madewithml.com/) - production ML engineering and MLOps lessons.
- [MLflow documentation](https://mlflow.org/docs/latest/ml/tracking/)
- [Full Stack Deep Learning](https://fullstackdeeplearning.com/)

## Recommended order

Git -> Docker -> experiment tracking -> data/model versioning -> FastAPI -> CI/CD -> monitoring -> orchestration -> Kubernetes -> cloud. Every deployed project should have tests, reproducible configuration, logging, a health check, and a rollback story.
