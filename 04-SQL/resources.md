# SQL for Data Science

- [Saifullah785/SQL-for-Data-Science](https://github.com/Saifullah785/SQL-for-Data-Science) - database theory, basic SQL, filtering, functions, GROUP BY, joins, subqueries, CASE, window functions, projects, exercises, and datasets.
- [rumon5h/Machine-Learning-Roadmap](https://github.com/rumon5h/Machine-Learning-Roadmap) - roadmap context for SQL, advanced SQL, statistics, probability, and ML.
- [SQLBolt](https://sqlbolt.com/) - short interactive SQL lessons.
- [PostgreSQL tutorial](https://www.postgresql.org/docs/current/tutorial.html) - authoritative relational database reference.

## Study order

Database concepts -> SELECT and filtering -> aggregation -> joins -> subqueries -> CASE -> window functions -> query plans -> data modeling -> analytics projects.
