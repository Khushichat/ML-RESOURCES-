# Machine Learning Resources

## Primary repositories

- [probabl-ai/scikit-learn-course](https://github.com/probabl-ai/scikit-learn-course) - source for the Machine Learning in Python with scikit-learn MOOC; course notebooks and material are CC-BY.
- [Nyandwi/machine_learning_complete](https://github.com/Nyandwi/machine_learning_complete) - 30+ notebooks across Python, data work, visualization, cleaning, classical ML, CV, NLP, and MLOps.
- [glouppe/tutorials-scikit-learn](https://github.com/glouppe/tutorials-scikit-learn) - beginner and intermediate scikit-learn tutorials; BSD 3-Clause.
- [justmarkham/scikit-learn-videos](https://github.com/justmarkham/scikit-learn-videos) - tutorial videos with corresponding notebooks.
- [akmand/machine_learning_tutorials](https://github.com/akmand/machine_learning_tutorials) - scikit-learn, clustering, neural networks, LightGBM, forecasting, and advanced topics.

## Recommended order

Foundations -> regression/classification -> trees and ensembles -> unsupervised learning -> pipelines and validation -> model selection -> interpretation -> specialized topics.
