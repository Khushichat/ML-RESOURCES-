# NLP Resources

- [nlp-with-transformers/notebooks](https://github.com/nlp-with-transformers/notebooks) - NLP introduction, text classification, transformer anatomy, tokenization, fine-tuning, datasets, and Transformers; Apache-2.0.
- [Hugging Face NLP Course](https://huggingface.co/learn/nlp-course) - current practical path for tokenizers, datasets, Transformers, and fine-tuning.
- [NLTK Book](https://www.nltk.org/book/) - classical NLP foundations.
- [spaCy course](https://course.spacy.io/en/) - practical linguistic pipelines.

## Recommended order

Text preprocessing -> bag-of-words and TF-IDF -> word embeddings -> RNN/LSTM -> attention -> transformers -> BERT -> Hugging Face workflows. Evaluate with task-appropriate metrics and inspect failure cases.
