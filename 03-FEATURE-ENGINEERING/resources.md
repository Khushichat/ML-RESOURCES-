# Feature Engineering Resources

- Local reference: *Feature Engineering for Machine Learning*.
- [CIS-Team/Data-Science-Roadmap](https://github.com/CIS-Team/Data-Science-Roadmap) - feature engineering, feature selection, interpretation, SHAP, and explainability.
- [scikit-learn preprocessing guide](https://scikit-learn.org/stable/modules/preprocessing.html) - production-oriented transformers and pipelines.
- [SHAP documentation](https://shap.readthedocs.io/) - current explainability API and examples.

## Practice order

Missing values -> outliers -> categorical encoding -> scaling -> feature selection -> dimensionality reduction -> imbalanced data -> SHAP. Every experiment should compare a baseline, avoid leakage, and record the validation protocol.
